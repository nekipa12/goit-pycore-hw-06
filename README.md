# goit-pycore-hw-06

Домашнє завдання до теми 9: основи роботи з класами. Класи для адресної книги, на яких далі будуватиметься бот-помічник.

## Структура

`address_book.py`:

- `Field` — базовий клас для полів запису
- `Name` — ім'я контакту, обов'язкове поле (не може бути порожнім)
- `Phone` — номер телефону з перевіркою: рівно 10 цифр
- `Record` — запис з іменем і списком телефонів, методи `add_phone`, `remove_phone`, `edit_phone`, `find_phone`
- `AddressBook` — книга контактів на основі `UserDict`, методи `add_record`, `find`, `delete`

## Запуск

Сторонні бібліотеки не потрібні, достатньо Python 3.

```
python address_book.py
```

Скрипт виконує приклад із завдання та показує, що некоректний номер у запис не потрапляє.
